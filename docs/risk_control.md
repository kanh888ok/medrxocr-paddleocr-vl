# 风险说明

## 数据来源

- 当前数据主要来自公开且已脱敏的数据集。
- 不把公开数据写成自采数据。
- 真实线下处方自采数据暂未补充。

## 数据合规

- 保留数据来源、许可证和用途说明。
- 缺失标注不补造。
- 当前核心评估集不使用合成处方。
- 实拍子集只替换公开 eval 图片，不重新标注。

## 医疗隐私

- 不公开未脱敏处方。
- 样本中保留 `pii_redacted` 标记。
- Demo 内置图片是合成脱敏样例，不是真实处方。

## 结果边界

- 当前结果主要证明公开词图 OCR 和小规模实拍子集上的效果。
- 不能写成完整临床系统。
- 不能写成已经覆盖真实线下处方。
- 结构化字段抽取仍是规则原型，需要人工标注和后续模型支持。
