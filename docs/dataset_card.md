# Dataset Card: MedRxOCR

## Dataset Name

MedRxOCR-Eval / MedRxOCR-Train

## Purpose

This dataset supports OCR and structured understanding of medical prescription images.

## Data Sources

See `docs/data_source_registry.csv`.

## Splits

Current fixed split files are generated by `scripts/create_submission_splits.py`.
The split assignment is deterministic and based on a stable SHA256 hash of
`source_id:image_id`.

Current processed files:

| File | Records | Notes |
|---|---:|---|
| `data/processed/medrxocr_train.jsonl` | 4801 | Training split |
| `data/processed/medrxocr_val.jsonl` | 607 | Validation split |
| `data/processed/medrxocr_eval.jsonl` | 1367 | Fixed evaluation split |

Source composition:

| Source | Train | Val | Eval | Notes |
|---|---:|---:|---:|---|
| `mendeley_bilingual_1000` | 681 | 110 | 206 | Full-page bilingual prescription OCR/KIE |
| `mendeley_bd_200_yolo` | 141 | 13 | 46 | Medicine-region detection |
| `rxhandbd_5578` | 3979 | 484 | 1115 | Official test set preserved as eval |

For RxHandBD, the official test set is preserved as evaluation data. A small
validation split is carved out of the official training set for SFT monitoring.

## Source Data Integrity Notes

No synthetic clinical prescriptions were added.

The Mendeley bilingual source contains 1000 image files, but the provided CSV
has 1001 image rows and only 997 unique image IDs after filename normalization.
The duplicate image IDs are:

- `0063`
- `0185`
- `0676`
- `0856`

Images without a unique CSV annotation:

- `0186`
- `0674`
- `0747`

Therefore this project reports 997 usable unique bilingual annotation records,
not 1000 completed structured annotations.

## Tasks

1. Full-page OCR.
2. Prescription field extraction.
3. Medication-line extraction.
4. Drug-name recognition and normalization.
5. Word-level handwritten prescription recognition.
6. Medicine-region detection.
