# Submission Checklist

## GitHub Repository

- [ ] README complete
- [ ] Dataset Card complete
- [ ] Model Card complete
- [ ] Annotation Guideline complete
- [ ] Privacy/License note complete
- [ ] Training config included
- [ ] Evaluation script included
- [ ] Quality audit script included
- [ ] Baseline result table included
- [ ] Demo included
- [ ] License included

## Data

- [ ] Source registry complete
- [ ] License of each data source checked
- [ ] PII removed or already de-identified
- [ ] Synthetic data excluded from core evaluation
- [ ] Evaluation split fixed
- [ ] Duplicate check complete
- [ ] Difficulty tags complete
- [ ] Dataset statistics generated

## Model

- [ ] PaddleOCR-VL zero-shot result
- [ ] PaddleOCR-VL-1.5 zero-shot result if possible
- [ ] LoRA SFT result
- [ ] Ablation: no lexicon vs lexicon normalization
- [ ] Hard-case breakdown

## Submission Email

- [ ] GitHub repository URL
- [ ] AI Studio dataset URL / Baidu Netdisk URL
- [ ] Hugging Face model URL or placeholder
- [ ] Technical report
- [ ] Demo URL or local demo instructions
