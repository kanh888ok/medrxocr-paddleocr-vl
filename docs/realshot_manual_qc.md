# 实拍图片人工质检表

## 质检范围

本表检查 20 张手机实拍图片是否可用于项目说明和实拍评估。

检查项：

- 图片是否能正常打开。
- 文字区域是否有足够可读性。
- 是否已匹配到对应原图。
- 是否属于固定 eval 划分。
- 是否可计入严格实拍评估。

质检明细见：

```text
docs/realshot_manual_qc.csv
```

## 质检结果

| 项目 | 数量 |
|---|---:|
| 实拍图片总数 | 20 |
| 图片可打开 | 20 |
| 清晰度通过 | 20 |
| 已确认对应原图 | 20 |
| 可计入严格 eval | 18 |
| 仅作采集示例 | 2 |

## 结论

20 张实拍图片均可作为真实拍摄样本使用，且均已匹配到原始公开处方图。

其中 18 张来自固定 eval 集，可沿用原标注作为严格实拍评估子集。另有 2 张来自 train 集，图片质量可用，但不计入严格 eval 指标，只作为采集示例。

## 说明

本质检只确认图像可读性、原图匹配关系和评估资格，不等同于药品字段级人工标注质检。

已在 `data/eval/realshot_eval_18.jsonl` 上补充 PaddleOCR-VL-1.5 零样本基线。结果见 `docs/realshot_baseline.md`。
