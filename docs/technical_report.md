# MedRxOCR Technical Report

## Project Summary

MedRxOCR targets multilingual medical prescription understanding with
PaddleOCR-VL. The task is broader than plain OCR: it covers full-page text
recognition, prescription field extraction, medicine-region detection,
word-level handwritten recognition, and JSON-structured output.

## Current Completion Status

Completed:

- Downloaded and verified three public CC BY 4.0 data sources.
- Converted source annotations into the MedRxOCR JSONL schema.
- Built fixed train/validation/evaluation splits.
- Generated PaddleOCR-VL-style SFT manifests.
- Generated quality audit and dataset statistics reports.
- Added explicit source-data integrity notes to avoid overstating dataset size.

Not yet completed:

- PaddleOCR-VL zero-shot benchmark.
- PaddleOCR-VL-1.5 zero-shot benchmark.
- LoRA SFT training run.

## Data Integrity Findings

The project does not fabricate missing labels or synthetic prescriptions.

The Mendeley bilingual source provides 1000 image files. Its CSV contains 1001
image rows, but only 997 unique image IDs after filename normalization. Four IDs
are duplicated: `0063`, `0185`, `0676`, and `0856`. Three images do not have a
unique CSV annotation: `0186`, `0674`, and `0747`.

For this reason, MedRxOCR reports 997 usable unique bilingual annotation records,
not 1000 completed bilingual annotations.

## Processed Splits

```bash
python scripts/create_submission_splits.py \
```

## Remote Smoke Test: PaddleOCR-VL-1.5

Environment:

- GPU: NVIDIA GeForce RTX 4090 vGPU, 49140 MiB total memory.
- OS: Ubuntu 22.04.5.
- PaddlePaddle GPU: 3.2.1, CUDA enabled.
- PaddleOCR: 3.5.0.
- Pipeline: `PaddleOCRVL(pipeline_version="v1.5")`.

A single-image smoke test was run on fixed eval sample
`rx_mendeley_bilingual_1000_0003`. This is not a full zero-shot benchmark and
must not be reported as final model performance.

| Model | Subset | Images | CER | Notes |
|---|---|---:|---:|---|
| PaddleOCR-VL-1.5 | single fixed-eval smoke image | 1 | 10.8082 | Output contained severe repetition/garbled text |

The output is saved in `outputs/remote_paddleocrvl_v15_smoke/`. A 5-image pilot
run was attempted, but the first prediction did not finish after more than 30
minutes, so the process was terminated to avoid wasting GPU time. This needs
further investigation before running a larger benchmark.
