# Scoring Mapping: MedRxOCR Submission Scope

This document maps the current repository to the challenge scoring dimensions
without overstating unfinished work.

## Evaluation Dataset Quality

Completed components:

- Public CC BY 4.0 prescription-related sources are registered with provenance
  and license notes.
- Source annotations are converted into a unified MedRxOCR JSONL format.
- Fixed train, validation, and evaluation splits are generated by
  `scripts/create_submission_splits.py`.
- Metadata includes `source_id`, `license`, `visual_tags`, `difficulty`, and
  `pii_redacted`.
- Quality-audit and dataset-statistics scripts are provided.

Current label scope:

The repository provides a unified schema and protocol for structured
prescription extraction; current released labels mainly cover full-page OCR
text, medicine-region detection, and word-level prescription OCR.

## Scenario Scarcity

MedRxOCR focuses on medical prescription OCR, including handwritten prescription
words, mixed printed/handwritten layouts, medicine-region localization, and
multilingual prescription text.

## Task Complexity

Current completed task coverage:

- full-page prescription OCR text conversion
- medicine-region detection data conversion
- word-level handwritten prescription OCR
- JSONL schema and SFT manifest generation
- lightweight slot-level baseline evaluation script

Planned extensions:

- full-page structured extraction benchmark
- stricter medication-line and field-alignment metrics
- lexicon-constrained decoding and normalization
- no-lexicon vs lexicon ablation

## Training Data Construction

Completed components:
